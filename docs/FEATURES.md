# Development feature map (0.2)

The program uses its own visual code. Vendor category names below identify
research references, not identical source algorithms. See REVISION-STATUS.md for unvalidated work.

| Category / capability | Development implementation |
| --- | --- |
| Oscilloscope | 15 templates, waveform/stereo XY/radial/wireframe forms |
| Lava Lamp | 9 procedural field templates |
| Interstellar | 6 starfield/core/orbit templates |
| Code | 5 glyph stream templates |
| Basic Colors | 6 two-color field templates |
| TV | 6 static, signal and field templates |
| Pixel | 10 quantized / particle templates |
| Text | 11 offered styles in its own mode; Warp, Expand, Spin, Glitch, Wave, Shake, Strobe |
| Plasma | 6 line geometry templates; two colors |
| Texture | Noise, Grain, CRT, Thresh |
| Dither | Randomized glyph-based Symbol, Star, Flower, Hex |
| Track | Basic, System, Bracket, Glow, Terminal |
| Glass | Ball, 2x2, Full, Flower, Cross, Burst |
| Images | Alpha/luminance contours including holes; Text background, scaling and clear |
| Fonts | TTF/OTF import; font files copied with saved User presets |
| Lyrics | Numbered editable rows, add/delete/clear, TXT import, beat/seconds cycles |
| MIDI | CC 0–127 parameters, confirmed hardware type, notes for buttons, persisted bindings |
| Recording | MP4/MKV; software or checked NVENC; configurable output; installer encoder under validation |
| Presets | Per-category Factory/User/Defaults, named saves, overwrite confirmation, browser and cycles |
| Graphics | Seven immediate tiers and overrides in FPS, percentages and levels; sampling is not MSAA/DLSS |
| Arcade | Excluded from current scope |
| Multiple / Performance | Disabled placeholders for later projects |

Four-band EQ, colored band assignments, animated GIF playback, Multiple and
Performance remain deferred. No current control claims that these are implemented.
