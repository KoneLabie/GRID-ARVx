# Local Text style fonts

The offered Text styles are Simple, Hand, VHS, System, Tarophis, Pixel, Ransom,
Noskale, Picnic, Flor and Myrtille. Normal is an unoffered legacy variant; its
numeric slot remains valid so existing states do not shift their style indices.

Set `GRID_STYLE_FONTS` to a local directory before opening the app. The directory
is remembered in complete state as `styleFontRoot`. The app loads these filenames
when the directory changes, with a 32 MB limit per font:

| Style | Filename |
| --- | --- |
| Simple | GenericG50.otf |
| Hand | ShadowHand.otf |
| VHS | VCRMono.ttf |
| System | DMMono-Regular.ttf |
| Tarophis | Tarophis.otf |
| Pixel | PressStart2P-Regular.ttf |
| Ransom | Ransom.ttf |
| Noskale | Noskale.otf |
| Picnic | PicNic.otf |
| Flor | FlorDeRuina.otf |
| Myrtille | Myrtille.ttf |

Missing fonts use basic system-font approximations. An individually imported font
overrides the style library. Native ornamental or pixel glyphs bypass the extra
simulated glyph treatment, while the independent Text effects remain available.

The reference library is external: no extracted font, shader, preset, thumbnail or
vendor branding is included in the source or installer. Local font metadata includes
a DEMO face name, a noncommercial notice, and several incomplete or differing notices.
Extraction alone does not establish redistribution rights. The optional library path
is machine-local; a shared preset does not copy the whole style library.

Untouched autogenerated Text defaults are upgraded to the revised style colors.
User presets and edited default files are preserved. Factory folders remain empty.
