# Public reference notes

Source: [Greyland Audio product page](https://greylandaudio.com/products/visual-lab-pro), checked 2026-10-11.
These brief paraphrases record documented behavior, not its internal implementation.

| Category | Documented idea |
| --- | --- |
| Oscilloscope | Glowing waveforms and adjustable shapes. |
| Lava Lamp | Organic blobs driven by frequency bands. |
| Arcade | Retro game-inspired visuals. |
| Interstellar | Stars, bursts, and imported shape outlines. |
| Code | Audio-driven letter/number streams. |
| Basic Colors | Amplitude/frequency-responsive color washes. |
| TV | Analog static and chromatic displacement. |
| Pixel | Limited palettes and coarse grids. |
| Custom Text | Reactive lyrics/titles; custom TTF/OTF fonts. |
| Plasma | Wave-like light and image outlines. |
| Multiple Mode | Independent visual tiles, up to 36. |
| Performance Mode | Live cues, setlists, and keyboard control. |

| FX family | Named styles |
| --- | --- |
| Texture | Noise, Grain, CRT, Thresh |
| Dither | Symbol, Star, Flower, Hex |
| Track | Basic, System, Bracket, Glow, Terminal |
| Glass | Ball, 2x2, Full, Flower, Cross, Burst |

The page advertises 20+ FX but explicitly names 19 styles above; additional names
were not verified. Its 10 visual categories exclude the two presentation modes.

No complete manual or video walkthrough was analyzed for this package. These
notes cannot establish proprietary algorithms, exact presets, host behavior,
or undocumented parameters. Further research and hands-on comparisons remain
necessary before implementing the advanced features.
